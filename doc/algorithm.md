        - fresh=0.6 -> 60% of EXPLOIT feed generated from ADJACENT. remaining 40% of EXPLOIT generated from using TOP-C vector as keyword directly
        - epsilon=0.2 -> 20% of entire feed is EXPLORE, remaining 80% is EXPLOIT.
- we'll build our own vector db based on embeddings generated by pretrained model.

- our current clustering candidate is the DBSCAN algorithm.
- ADJACENT: we take random edge vector within the cluster (border points) as query.
    - note that here, we can have further control over 'adjacency radius' via eps parameter, which defines the size of cluster neighborhood.

- EXPLORE: take the centroid average of a cluster (maybe its border points) as a vector, do nearest lookup in word2vec and use that as token to query news api and get new articles.
